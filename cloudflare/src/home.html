FILE & MEDIA TOOLS / 001–002

路径与素材，都顺手。

复制路径与小红书工具共用一个客户端。小红书功能从 v0.2.0 起提供，各平台能力见下方说明。

01

顺着熟悉的入口来。

桌面端可以在 Finder 或资源管理器中右键复制，也可使用 Option+P / Alt+P。Android 支持系统选择器、文件管理器分享和应用内复制。

02

格式，按你的习惯。

绝对或相对路径、引号、分隔符、多选连接方式，都能设置。修改后实时预览，偏好自动保存在当前设备。

03

只处理路径，文件留在本机。

复制路径不读取文件内容，也不会上传你的文件。不需要登录账号，选中文件，复制后继续手头的事。

04

一篇笔记，一次收好。

选择小红书原图和视频清晰度，保存原视频候选、文案与实况配对素材，或打包 ZIP。Android 也能复制、分享所选原图。

05

整页内容，按节奏保存。

macOS 和 Windows 支持主页批量下载，自定请求间隔，暂停后继续，失败项单独重试。Android 提供单篇下载，主页批量在桌面客户端使用。

06

让一个瞬间，动起来。

本地图片或视频可合成实况照片，选择片段、封面、倍速与声音，导出 JPEG／HEIC + MOV 或 .pvt 实况包。开始前会检测设备的编码能力。

安装前，你可能想知道。

小红书功能在各平台有什么区别？

Windows、macOS 和 Android 均可单篇下载与制作本地实况，原视频以笔记实际提供的候选为准；主页批量下载与小红书网页登录在桌面客户端使用。桌面提供内置 Python 备用引擎；Android 的 Python 选项为在线备用解析，会将输入的笔记链接发送给解析服务。实况合成在本机完成，是否可编码取决于设备。

macOS 和 Windows 首次安装有什么提示？

macOS 版本尚未经 Apple 公证，首次打开可能需要在「系统设置 → 隐私与安全性」中允许此应用。Windows 安装器尚无公开发行签名。请使用本页指向的官方安装包，并查看对应版本的发布说明。

Android 显示 content://，是复制出错了吗？

部分文件管理器和云盘只提供内容 URI。Brclio 会保留真实 URI；能够确定真实主共享存储位置时，才会映射为本机路径。Android 版本支持 Android 8.0 及以上。

下载或更新失败怎么办？

可前往 GitHub 官方发布页重新下载，或在客户端的「通用设置 → 版本更新」中检查新版本。内置更新代理开关是否可用，请以你安装版本的发布说明为准。
