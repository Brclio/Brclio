# Brclio 下载器便捷版

macOS 13 或更新版本选择对应芯片的 DMG，将 **Brclio Downloader Lite** 拖入“应用程序”，双击打开。Windows x64 直接运行便捷版 EXE。便捷版使用 Go 原生程序，通过默认浏览器显示本机下载进度，用户无需安装 Go、Node.js、Electron 或单独的 VPN 软件。

macOS 将 Brclio 本体安装到系统应用程序目录 `/Applications/Brclio.app`，并从这个位置判断版本和打开应用。若旧版下载器曾安装到 `~/Applications/Brclio.app`，请先退出那份 Brclio，再运行新版下载器。新版会保留用户目录中的旧副本。两份 Brclio 使用同一个应用标识，通常会读取同一套本地设置。系统目录不可写时，下载器会提示所需权限。

macOS 启动后会保留一个静止的 Dock 图标。点击图标可重新打开本次运行的下载页面；任务完成后也可以从 Dock 退出。

打开后自动检查最新稳定版 Brclio。已安装同版或更高版本会直接打开，其余情况下载官方安装包，核对发布清单、完整文件大小和 SHA-256，再安装并打开。遇到临时网络错误会重新检测代理，最多自动重试两次。之后仍可点击“下载或升级 Brclio”继续；匹配同一文件摘要的部分会按字节续传。安装成功后会清理便捷版缓存中的已验证安装包。

每次启动、手动下载或升级都会重新选择线路。对目标地址检测到系统代理时优先使用电脑的代理。没有代理时，读取后台最新订阅，并发测速后通过延迟最低的可用节点访问 GitHub。代理订阅仅用于本机下载器的请求。仅通过透明隧道接管流量的工具，可能无法从系统代理配置识别。

“启动时自动检查便捷版更新”可以关闭，仍能下载最新 Brclio。点击“升级便捷版”会独立检查便捷版的新包，安装后重新打开。便捷版目录、应用标识和发布通道与完整版下载器独立。界面监听回环地址的随机端口，浏览器只能凭本次启动的本地令牌执行下载操作。点击“退出”关闭便捷版；关闭网页后，空闲的后台会自行退出。

## 构建和验证

从仓库根目录运行：

```sh
(cd lite && go test ./... && go vet ./...)
bash lite/tools/build.sh
```

在 Mac 上可以生成两个 macOS DMG 和 Windows x64 可直接运行的 EXE，输出目录为 `release/lite/`。 macOS 使用 ad-hoc 签名，Windows 版本没有 Authenticode 签名。命令行支持 `--version` 显示便捷版版本，`--check` 仅检查最新 Brclio 和网络线路。

推送与 `lite/VERSION` 匹配的 `lite-vX.Y.Z` 标签会触发便捷版的独立发布工作流。校验清单和安装包写入版本标签，`lite-stable/latest.json` 指向当前便捷版。两个 GitHub Release 均标为 prerelease，并设置 `latest=false`。
