# Brclio 终端的账号数据

终端默认使用本机存储。在「连接中心 → 账号同步」开启同步后，当前设备会与已登录的 Brclio 账号同步主机和端口转发模板。开关按设备、按账号保存。关闭后可继续在本机使用和编辑配置。关闭开关不会删除其他设备已经同步的副本。

## GitHub 存储

服务使用现有账号服务配置的私有仓库 `BrclioData/BrclioUserData`。终端独占记录 `users/<Brclio 用户 ID>/apps/terminal/data.json`。用户名、邮箱和 GitHub 登录名都不作为存储路径。下例使用虚构数据。

```json
{
  "version": 1,
  "revision": 3,
  "updatedAt": "2026-11-28T10:00:00.000Z",
  "data": {
    "hosts": [
      {
        "name": "测试机",
        "host": "server.example.test",
        "user": "dev",
        "port": 22,
        "group": "开发/测试",
        "tags": ["测试"],
        "favorite": true
      }
    ],
    "forwards": [
      {
        "name": "开发预览",
        "type": "local",
        "connection": {"host": "server.example.test", "user": "dev", "port": 22},
        "listenHost": "127.0.0.1",
        "listenPort": 8080,
        "destinationHost": "127.0.0.1",
        "destinationPort": 3000
      }
    ]
  }
}
```

服务端从已验证的会话确定用户目录。写入时再次验证账号、会话有效期和版本号。并发更新使用 Git 事务；已有更新时返回 HTTP 409。客户端以先前同步的版本、本机版本和云端版本合并，遇到同一配置的冲突时由用户选择。读取和写入均有字段校验。

以上配置以明文 JSON 保存。仓库授权读者可以读取 Git 历史。设备上的私钥文件、密码库、最近连接和终端输出不在同步字段中。服务器认证使用现有 Brclio 会话。桌面客户端不持有资料库的 GitHub 写入凭据。

## 本机账号切换

登录状态已验证后，当前账号有独立的本机主机库、最近记录和转发模板。程序使用本机当前登录令牌的摘要来识别上次验证过的账号，离线重开后仍能识别。新令牌须重新确认账号身份。退出和更换登录令牌会关闭当前终端视图及其连接。旧版未绑定的主机配置可从同步窗口手动移入当前账号。

## 桌面功能对照

| 用户操作 | 当前实现 |
| --- | --- |
| 打开本地终端 | 默认在主窗口内打开，支持弹出和收回原会话、多标签、分屏和保存布局 |
| 连接服务器 | 快速连接、主机分组、标签、收藏、最近记录、OpenSSH 跳板链和本机私钥选择 |
| 管理文件 | 图形 SFTP 浏览、上传、下载、重命名、建目录、删除，以及交互式 SFTP 标签 |
| 管理连接与信任 | 本地、远程和动态端口转发，SSH 身份、Ed25519 密钥生成、已知主机指纹 |
| 设备与其他协议 | Telnet、串口设置、Mosh。Mosh 使用本机客户端，在 Windows 使用默认 WSL 发行版，远端也需要 mosh-server |
| 会话日志 | 登录后可为选定的单个窗格开启本机录制、查看及删除日志、添加和跳转书签 |
| 跨设备 | 开关控制本账号桌面主机和转发模板的同步，云端记录按 Brclio 用户 ID 隔离 |

团队授权、会话实时协作、企业 SSO 等尚未实现。AI 和手机配对沿用此前确定的范围。参照 [Termius 官方功能表](https://www.termius.com/pricing)。
