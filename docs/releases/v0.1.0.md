Brclio 的第一个版本，从“复制路径”开始。

### 支持的功能

- Windows 文件 / 文件夹右键复制；macOS Finder 快速操作 / 服务。
- 安卓文件选择、文件夹选择、分享导入与应用内长按复制。
- 默认绝对路径；相对路径与可配置基准文件夹。
- 引号、分隔符、文件夹末尾分隔符、多条路径连接格式。
- 实时预览、偏好自动保存、本机处理，无需账号。
- 设置中检查 GitHub 新版本、下载进度、SHA-256 校验与系统安装入口。

### 安装包

- Windows x64：EXE 安装向导。
- macOS Apple Silicon / Intel：对应架构 DMG，也提供 ZIP。
- Android 8.0+：使用固定项目发布密钥签名的正式 APK。
- SHA256SUMS.txt：全部六个包的校验值。

### 使用说明

桌面系统右键入口需要在软件内点击启用；Windows 11 通常位于“显示更多选项”，Windows 系统菜单首版支持单项。macOS 在 Finder 的“快速操作”或“服务”中使用，软件内支持多项复制。

Android 没有通用的系统右键扩展，使用选择器、分享入口及应用内长按；部分来源仅提供 content URI，Brclio 会标记并保留真实地址。

Windows / macOS 首版未配置开发者代码签名，macOS 未公证，启动时可能需要系统安全确认。macOS 在线更新会下载并校验 DMG，仍需将 Brclio 手动拖入 Applications。安卓更新会交给系统安装器，首次需要允许 Brclio 安装应用。

界面基于 Brclio Design System。源码、构建和发布说明见仓库 README。
