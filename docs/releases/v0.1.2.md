macOS 复制路径现在直接出现在 Finder 右键菜单第一层。

### 新功能与修复

- 使用原生 Finder Sync 扩展显示“复制路径 · Brclio”，无需进入“服务”子菜单。
- 支持文件、文件夹、多选及文件夹空白处；空白处复制当前文件夹路径。
- 继续使用客户端中保存的绝对/相对路径、基准文件夹、引号和文件夹末尾斜杠设置；主程序关闭时也可复制。
- 启用新入口成功后，只清理属于 Brclio 的旧“服务”项，保留其他服务和扩展。
- 修复 Finder 远程菜单未保留选区数据的问题，保留中文、空格、特殊字符和 emoji 文件名。
- 发布前检查 Apple Silicon、Intel 扩展的版本、架构、完整签名、独立沙盒与 URL 入口，验证应用、DMG 和 ZIP；所有平台检查通过后才发布。

### macOS 使用

退出旧版 Brclio，将新版拖入 Applications 替换后打开，在“复制路径”页点击“启用右键菜单”。如系统要求批准，请在系统设置的 Finder 扩展中允许 Brclio。之后右键直接选择“复制路径 · Brclio”。少数系统虚拟目录、特殊视图或重叠扩展可能受 Finder 限制。

当前仍为 ad-hoc 签名，尚无 Developer ID 和 Apple 公证。首次下载若提示无法验证开发者，请到“系统设置 → 隐私与安全性 → 仍要打开”允许本应用；无需关闭系统安全保护。macOS 在线更新会下载并校验 DMG，再手动替换应用。

Windows、Android 安装包同步更新到 0.1.2，Android versionCode 为 3，沿用原发布密钥。
