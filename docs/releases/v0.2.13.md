# Brclio 0.2.13

账号密码、Google 和 GitHub 现在可以登录同一个 Brclio 账号。用已有方式登录，点击工具箱右上角的账号名称，打开「账号设置」，即可查看已关联的方式、设置密码或关联另一个第三方账号。[网页账号中心](https://tools.brclio.com/account)

在桌面客户端关联 Google 或 GitHub 时，先在系统浏览器选择第三方账号，再回到客户端核对两个邮箱并点击「确认关联」。两个邮箱可以不同。若所选身份或邮箱已归属其他 Brclio 账号，客户端会提示冲突。关联完成后，用新方式登录即可继续使用原来的资料和复制偏好。

本版提供 Windows x64、Apple 芯片 Mac 和 Intel Mac 安装包。已安装桌面版可在「通用设置 → 版本更新」检查更新。
