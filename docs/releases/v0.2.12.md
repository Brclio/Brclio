# Brclio 0.2.12

在工具箱右上角打开「登录 / 注册」，选择「使用 GitHub 继续」，即可在系统浏览器完成授权并确认登录客户端。[网页账号中心](https://tools.brclio.com/account) 也支持 GitHub 登录。

首次授权时，Brclio 会使用 GitHub 已验证的主邮箱关联已有 Brclio 账号，保留原有设置和数据。新用户会自动注册。登录仅申请读取邮箱，GitHub 用户名或主邮箱变更后仍通过原 GitHub 身份登录。

使用第三方邮箱注册的 Google 账号，首次关联时需先验证邮箱或用原方式登录，再到网页「账号设置」选择「关联 Google」。已关联的 Google 账号仍可直接登录。

本版提供 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包。已安装桌面版的用户可在「通用设置 → 版本更新」检查更新。
