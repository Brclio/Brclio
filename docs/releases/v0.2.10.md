# Brclio 0.2.10

- 小红书笔记解析被安全检查拦截时，会显示触发的规则、可披露的目标主机和重试建议，隐去链接参数和凭据。
- 打开「通用设置 → 查看日志与反馈」可预览和复制本机最近 7 天的诊断日志。遇到小红书报错时也可直接进入反馈。登录后可提交问题或改进建议，并选择是否附上日志。
- 管理员可在[客户端管理后台](https://tools.brclio.com/admin)查看反馈、更新状态和记录处理结果。后台可复制私有问题链接、AI 维修资料和项目 Skill 指令。

本次提供 macOS Apple silicon、macOS Intel 和 Windows x64 桌面安装包。
