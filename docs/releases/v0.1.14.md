本次更新将下载中断后的重试改为断点续传。

### 保留下载进度

- 网络中断或超时后保留已下载的部分，自动重试时从实际已写入的位置继续请求剩余内容。最多自动重试 10 次的规则不变。
- 重试次数用完后可点击“继续下载”；重启客户端后，再次下载同一安装包也会恢复匹配的进度。设置与关于窗口显示累计进度。
- 每次尝试仍遵守系统代理优先；使用内置代理时重新获取当前订阅并选择延迟最低的可用节点。更换节点后继续下载剩余内容。
- 续传资料绑定版本、官方文件地址、总大小和 SHA-256，严格核对 HTTP 范围。完成后验证整个磁盘文件的大小及 SHA-256，通过后才允许安装。
- 文件身份变化时清理旧片段；服务器未接受续传而返回完整文件时，界面会明确提示并安全重新下载。证书、范围、完整性与本地文件错误不会混拼内容。

### 发布与安装

- Windows x64、macOS Apple silicon、macOS Intel 与 Android 同步为 0.1.14；Android `versionCode` 递增为 15，沿用现有正式签名。
- 保留桌面覆盖安装、启动确认与失败回滚；Android 完成后继续验证包名、版本及正式签名。
- 账号、后台订阅配置和现有私有数据仓库不变，无数据迁移。续传资料仅存于本机。
- macOS 沿用 ad-hoc 签名，尚未公证；Windows 外层安装程序尚未采用 Authenticode 发行签名。
