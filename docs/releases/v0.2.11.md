# Brclio 0.2.11

- 小红书单篇视频预览和「下载所选视频」默认使用笔记推荐的播放清晰度。需要原文件时可在清晰度菜单中选择原视频。整篇保存和主页批量归档继续优先保存可用的原视频。
- 视频下载进度显示已传输字节、平均速度和耗时。图文笔记的单张原图可直接选择文件名与保存位置，也可从原图预览在系统浏览器中打开。多图复制到剪贴板时会说明如何粘贴。
- 导出原图 ZIP 时减少了逐张写入再读回的磁盘开销，保留图片格式、视频轨道和归档大小校验。桌面 Python 引擎不可用时会自动切回 Node。
- 主页批量下载会在进入页签时确认小红书登录状态；翻页完成后及时识别列表末尾，再按设置的间隔逐篇保存。已有任务可以继续，失败项可以单独重试，也可以转入单篇下载。转入时会清空上一条笔记的结果。

本次提供 macOS Apple Silicon、macOS Intel 与 Windows x64 正式安装包。
