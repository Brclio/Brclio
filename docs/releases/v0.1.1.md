修复 macOS 首次下载后出现“Brclio.app 已损坏，无法打开”的打包问题。

### 修复内容

- 为 Apple Silicon 和 Intel 的完整应用及嵌套程序生成有效的 ad-hoc 签名；v0.1.0 跳过了应用重签名，残留的 Electron 签名无法通过系统完整性校验。
- 发布前分别检查构建应用、DMG 内应用和 ZIP 内应用的严格签名、版本、标识与架构，并运行最终打包应用的原生启动及路径复制测试。任何检查失败都会停止发布。
- 同步各平台版本为 0.1.1，Android versionCode 递增为 2，保留原发布签名。

### macOS 首次打开

下载对应架构的 DMG，把 Brclio 拖入 Applications 并替换旧版，然后打开。当前版本尚无 Developer ID 签名和 Apple 公证，首次可能提示无法验证开发者：到“系统设置 → 隐私与安全性 → 仍要打开”，再确认“打开”。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。允许后可以正常再次打开。

本次修复完整性签名，不代表已获得 Apple 公证。macOS 在线更新仍需下载后手动拖入 Applications。Windows、Android 的路径复制和更新功能保持不变。
