实况照片保留原始或裁切后的分辨率，取消默认长边 1440 像素缩图。JPEG 使用最高质量参数，HEIC 本地编码质量提高至 100，并支持更大的原始照片。封面预览直接来自原始画面，避免从动态视频再次截帧压缩。

每张图片可独立自由裁切、选择常用比例、按原图像素调整，支持旋转、翻转、亮度、对比度和饱和度。可将同一组调整应用到全部图片；固定比例按每张图片的原始尺寸分别计算。编辑仅记录设置，生成时从原文件绘制，原文件保留。调整、重排或移除素材后，预览和导出保持一致；统一调整支持取消。

动态 MOV 优先采用原始尺寸和随像素数增加的高画质码率，设备不支持时使用较小的可编码尺寸，并对大图备用画幅进行 16 像素对齐，避免部分硬件编码器额外平滑。结果分别显示照片与动态分辨率。大图片组仍可明确选择压缩导入，副本长边最高 4096 像素，并按图片张数分配像素预算。

下载小红书实况素材时，动态源优先选择最高分辨率，其次比较码率。普通视频继续沿用原有声音和兼容性选择规则。

Windows x64、macOS Apple silicon、macOS Intel 与 Android 同步为 0.2.4，Android versionCode 递增至 21，沿用现有正式签名。六个安装包与 SHA-256 清单由同一源码提交的发布流水线构建和核验后统一公开。

macOS 继续使用 ad-hoc 签名且尚未公证，Windows 外层安装器仍无 Authenticode 发行签名。
