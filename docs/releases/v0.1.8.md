在 Finder／Windows 资源管理器中选中文件或文件夹，按快捷键直接复制路径，沿用你的路径格式设置。

### 复制所选路径的快捷键

- macOS 默认 `Option+P`，Windows 默认 `Alt+P`，支持一个或多个文件、文件夹。
- 在“通用设置 → 复制所选路径”中点击“修改快捷键”，录入新的组合键后自动保存；可取消或恢复默认。
- 复制沿用相对路径及基准文件夹、引号、分隔符、目录末尾分隔符和多选连接方式。成功复制后不会切换到工具窗口。
- 新组合被占用或保存失败时保留原设置；启动遇到占用时，可在设置中重试启用或更换组合键。恢复默认复制格式会保留快捷键设置。
- 未选中有效项目、前台应用不符或无法确认当前选区时，保留原剪贴板并提示原因。

### 使用条件

- 快捷键需要 Brclio 正在运行，窗口最小化也可使用。macOS 关闭窗口后仍可用，退出软件后停止；Windows 关闭最后一个窗口会退出软件。
- macOS 首次使用可能请求允许 Brclio 控制 Finder。若拒绝，可在“系统设置 → 隐私与安全性 → 自动化”中允许后重试。现有 Finder 右键菜单和工具栏无需此授权。
- Windows 11 尝试根据活动视图读取当前标签页选区；只有视图无法访问或仍存在歧义时，才提示将目标页移到独立窗口后重试，避免复制后台页选区。
- 浏览器预览和 Android 不支持桌面全局快捷键。Android 保留现有选择、分享和应用内复制入口，版本同步为 0.1.8，versionCode 为 9。

### 安装与更新

- 可在软件中检查并下载安装更新，也可使用本页安装包覆盖安装，保留本机偏好。
- macOS 仍采用完整 ad-hoc 签名，尚未经 Apple 公证；Windows 安装器本身尚无公开 CA 发行签名。Android 沿用项目发布签名。
- 安装包与 SHA-256 校验清单由同一提交的发布流水线生成。打包、验签和应用启动检查与真实 Finder／资源管理器选区验收分别记录，不能互相代替。
