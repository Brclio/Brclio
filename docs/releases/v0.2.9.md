macOS 主窗口的侧栏和工具栏现在延伸到窗口顶边，左上角保留原生红黄绿按钮。可拖动顶部空白处移动窗口，帮助和登录按钮仍可直接点击。

本次提供 macOS Apple silicon、macOS Intel 和 Windows x64 桌面安装包。macOS 另附 ZIP 供客户端自动更新。下载文件可用本页的 SHA256SUMS.txt 校验。

Android 从本版起暂停发布新 APK。最后一个已发布的 Android 安装包是 [v0.2.8](https://github.com/Brclio/Brclio/releases/download/v0.2.8/Brclio-0.2.8-android.apk)，可用[该版本校验清单](https://github.com/Brclio/Brclio/releases/download/v0.2.8/SHA256SUMS.txt)核验。已安装的安卓客户端可继续使用。手动检查更新时，旧客户端可能提示找不到新版 APK。
