# Brclio 0.2.17

Brclio 终端现在把主机、常用命令和外观放在会话旁的侧栏。查找主机、编辑命令或预览配色时，当前终端仍可输入并查看输出。侧栏可以收起，终端也可以弹出为独立窗口，收回后继续原来的会话。

- 在 **SSH 主机** 侧栏中可以保存、编辑和收藏主机，按名称或地址搜索。最近连接会显示上次发起时间，可直接重连。
- **常用命令**支持新建收藏，也可以从历史中收藏。选中命令后填入当前窗格，按回车执行。命令历史由用户在本机开启。SSH 会话的自动记录需要远端 Shell 提供命令标记。
- **终端外观**提供 Brclio 深色、纸张浅色和深海蓝三种配色。字体、字号和光标支持实时预览，保存为默认设置后会用于新会话。

本版提供 Windows x64、Apple 芯片 Mac 和 Intel Mac 安装包。已安装 Brclio 的用户可在「通用设置 → 版本更新」检查更新。
