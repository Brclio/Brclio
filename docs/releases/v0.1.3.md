下载更新后覆盖安装，并自动打开新版 Brclio。

### 更新体验

- 设置中的“下载并安装更新”会连续完成下载、SHA256 校验和安装。
- macOS 在当前应用所在目录替换完整应用包，保留设置与 Finder 右键入口；不用再次拖拽 DMG。
- Windows 在原安装目录覆盖安装，保留设置与属于 Brclio 的右键菜单，完成后自动启动。
- 桌面端等待新版界面初始化成功、安装路径、版本与进程确认，再清理旧版备份；未启动成功时尝试恢复并重新打开旧版。
- 准备失败时保留已校验下载，可直接重试安装；安装目录不可写时保持旧客户端运行。
- Android 继续由系统确认 APK 覆盖安装。安装完成尝试自动打开；Android 15 等系统限制后台启动时，请点击安装成功页的“打开”。不增加悬浮窗或辅助功能权限。

### 首次迁移

v0.1.2 及更早版本未包含自动覆盖安装模块。请先退出旧版，将 v0.1.3 安装一次；从 v0.1.3 更新到后续版本即可使用新流程。

macOS 仍为完整 ad-hoc 签名，尚无 Developer ID 和 Apple 公证。首次下载若系统要求允许打开，请到“系统设置 → 隐私与安全性 → 仍要打开”允许本应用。更新不会关闭 Gatekeeper，也不会移除下载隔离标记。

Android versionCode 为 4，沿用原发布密钥。
