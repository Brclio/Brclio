Brclio 新增小红书媒体工具，保留现有账号登录、路径偏好、系统复制入口与在线更新。

### 小红书单篇下载

- 解析笔记长链接、短链接、完整分享文案和原图链接；桌面支持本地 Node / Python 双引擎，Android 保留本地解析和在线 Python 备用路径。
- 预览、勾选、反选、保存或复制原图；可导出文案 TXT、原图 ZIP，以及包含所选原图、实况 MP4 和文案的素材 ZIP。
- 支持普通视频清晰度及笔记声明的原视频候选，原生保存、进度、取消和媒体轨道检查。原始候选不等同于保证画面一定无水印。
- Android 支持系统分享笔记文案进入单篇页，以及复制、分享所选原图。

### 主页批量与实况

- 桌面支持独立小红书网页登录、主页顺序下载、自定义间隔、暂停继续、失败重试、失败筛选和链接转单篇。任务保存在本机，完成文件校验后跳过。
- 本地图片或视频可制作 0.5–8 秒实况，选择起点、封面、倍速、图片顺序、动效和声音，导出配对 JPEG / HEIC + MOV 或 `.pvt` ZIP。
- 实况制作依赖设备 WebCodecs 能力；界面在开始前检测。手机照片 App 对实况的最终识别仍以接收设备为准。

### 保留与发布范围

- 不迁入源下载器的会员、激活码或支付系统；Brclio 现有登录和用户数据路径保持，清除小红书会话不会退出 Brclio。
- Windows x64、macOS Apple silicon、macOS Intel 与 Android 同步为 0.2.0；Android versionCode 递增至 17，沿用现有正式签名。
- 桌面安装包内置目标平台的 Python 后台，用户无需额外安装 Python。安装包和校验清单继续由官方 GitHub Release 提供。
- macOS 沿用 ad-hoc 签名且尚未公证，Windows 外层安装器尚无 Authenticode 发行签名。
