# Brclio 0.2.14

在桌面客户端左侧打开「功能建议广场」，登录后即可查看所有用户发布的建议。点击「写建议」，填入名称和描述，也可以加上类别，方便其他人了解你的使用场景。

展开一条建议的「评分与讨论」，可以点星星打分或发表评论。点击星星左半边可打半星，评分范围为 0.5 至 5 星。广场显示平均分和评分人数，修改自己的评分后，每人仍只计一票。点击「刷新」可以看到新评论，并保留正在输入的评论。

广场中的建议和评论对所有已登录用户可见。如需向维护者私下报告问题或附上诊断日志，请使用「通用设置 → 查看日志与反馈」。

本版提供 Windows x64、Apple 芯片 Mac 和 Intel Mac 安装包。已安装 Brclio 的用户可以在「通用设置 → 版本更新」检查更新。
