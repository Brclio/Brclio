# Brclio 0.2.16

Brclio 终端默认在主窗口内打开。点「弹出窗口」可以独立使用，点「收回主窗口」即可返回。切换时，正在运行的命令、标签、分屏和滚动记录都会保留。修复了新增终端入口后侧栏底部版本号下移的问题，滚动工具列表时版本号保持在原位。

在终端的「操作」中可以搜索所有窗格、保存常用布局、导入 iTerm2 配色、管理 SSH 和 SFTP 连接配置。tmux 用户可以分离工作区，之后再连接到原来的会话。Windows 上的 tmux 需要在 WSL 发行版中安装。

本版提供 Windows x64、Apple 芯片 Mac 和 Intel Mac 安装包。已安装 Brclio 的用户可在「通用设置 → 版本更新」检查更新。各项 iTerm2 桌面功能的支持范围及待实现项目见[逐项兼容清单](https://github.com/Brclio/Brclio/blob/v0.2.16/docs/terminal-compatibility.md)。
