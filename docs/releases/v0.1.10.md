网页与客户端加入可选账号，将复制格式偏好带到其他设备。

### 注册与登录

- 支持账号名、邮箱、6 位邮件验证码和密码注册。验证码有效期 10 分钟，重发间隔 60 秒；账号名支持 3–32 位文字、数字及部分常用符号，密码为 8–128 位字符。
- 支持账号名加密码、邮箱加密码登录，也可使用 Google 注册及登录。
- Google 已验证邮箱会自动绑定同邮箱的现有账号；重复注册提示前往登录，首次 Google 注册可在账号设置中完善昵称、账号和密码。
- 网页提供独立账号页面；Windows、macOS 和 Android 使用同一套账号界面与接口。
- 客户端的 Google 登录在系统浏览器中完成，并要求在网页确认登录当前客户端。通过一次性设备请求和 SHA-256 验证证明交接会话，可取消，五分钟超时。
- 桌面与 Android 会话保存在原生应用的私有本机配置中，Bearer 不返回网页渲染层；网页使用 HttpOnly、Secure Cookie。

### 用户数据与复制偏好

- 继续使用现有私有 GitHub 数据仓库，以 `users/<用户ID>/` 为每位用户创建独立目录，保存 `profile.json`、`credentials.json` 与 `data.json`，共享索引为 `users/_index.json`。
- 档案与偏好以可读 JSON 保存；按产品所有者要求，应用账号密码在各自用户目录中以 `passwordPlaintext` 明文保存，并保留 PBKDF2-SHA256 哈希用于验证。仓库及 Git 历史的读者可读取密码；旧账号在下次成功密码登录或设置密码时补写。验证码和会话标识保存摘要。邮件应用密码、Google 客户端密钥及 GitHub 访问令牌仅保存在服务端配置中。
- 用户可以手动上传、读取和应用路径类型、引号、分隔符、文件夹末尾分隔符及多选连接方式。实际文件路径、相对路径基准文件夹、快捷键和开机启动设置留在本机。
- 复制路径、本机格式转换及偏好保存继续无需账号。邮件验证码、Google 授权与云端偏好需要网络连接。
- 私库写入通过同一次 Git 提交更新索引和用户文件，以非强制分支更新处理并发；不增加 R2、D1、KV、Durable Objects 或付费存储。
