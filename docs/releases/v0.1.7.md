Windows 11 的“复制路径 · Brclio”改用原生第一层右键菜单，无需进入“显示更多选项”。

### Windows 右键菜单

- 支持文件、文件夹、多选和文件夹空白处，沿用已保存的路径格式设置。
- 采用原生 Explorer 命令和已签名身份包，无需购买代码签名证书或开启开发者模式。
- 首次启用及签名证书变化时，需要通过 Windows 管理员授权，将 Brclio 专用公开证书加入 TrustedPeople。不会写入 Root 信任库。
- 已启用旧菜单的用户打开新版时会尝试迁移；新版注册成功后再清理旧入口。失败时保留可用的旧入口并显示错误。
- 修复注册中断时的旧入口恢复，以及多账户共享安装时的扩展文件保留和逐账户卸载清理。
- Windows 10 保留原有经典右键入口。新安装默认关闭右键集成，可在“复制路径”页面启用或停用。

### 安装与更新

- 可在软件中检查并下载安装更新，也可使用本页安装包覆盖安装，保留偏好。
- 首次迁移可能需要重新打开资源管理器窗口，或注销后登录，使菜单刷新。
- macOS 和 Android 同步版本号，保留现有功能；Android versionCode 为 8，沿用原发布密钥。
- Windows 安装器本身尚无公开 CA 发行签名；内置菜单扩展使用 Brclio 专用签名。macOS 使用完整 ad-hoc 签名，尚未经 Apple 公证。
- 所有安装包均提供 SHA-256 校验清单。
