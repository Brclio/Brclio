本次更新改进账号同步，保留原有复制路径、系统集成和自动更新功能。

### 账号与同步

- 保存复制格式偏好时携带云端版本号；其他设备已更新时提示重新读取，保留本机数据，避免把旧偏好直接覆盖到云端。
- 应用云端偏好时，先确认本机保存成功，再更新界面与实际复制格式；保存失败时继续使用原有设置。
- 沿用现有账号与登录接口，可与已接入的程序共用账号。账号及各程序的个人数据按用户独立保存，程序全局配置另行存放。
- 复制路径和本机偏好继续无需登录，也可离线使用。实际文件内容、路径、快捷键和相对路径基准不上传。

### 安装与更新

- Windows x64、macOS Apple silicon、macOS Intel 与 Android 同步为 0.1.11；Android `versionCode` 递增为 12，沿用现有正式签名。
- 保留安装包大小及 SHA-256 校验、桌面覆盖安装与启动确认流程。六个安装包和 `SHA256SUMS.txt` 完整核验后一起发布。
- Android 新包上传前会与上一正式版比较签名证书，确保可以沿用原应用身份升级。
- macOS 沿用 ad-hoc 签名，尚未加入 Apple 公证；Windows 外层安装程序尚未采用 Authenticode 发行签名。已有设置在升级时保留。
