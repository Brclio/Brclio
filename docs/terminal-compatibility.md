# Brclio 桌面终端与 iTerm2 3.7.6

核对日期为 2026-11-28。基准固定为 iTerm2 3.7.6（2026-10-15 构建）。上游程序面向 macOS，Brclio 使用 xterm.js 渲染，使用 node-pty 连接本机的 Unix PTY 或 Windows ConPTY。下表核对 Brclio 工作树中的可观察行为。官网文档持续更新，新版本独有功能不能据此计入 3.7.6。[固定版本说明](https://raw.githubusercontent.com/gnachman/iTerm2/v3.7.6/README.md) · [官方版本记录](https://iterm2.com/downloads.html) · [Brclio 终端入口](../desktop/terminal/terminal.js) · [PTY 实现](../desktop/terminal/pty.cjs)

“可用”表示有可操作入口和对应实现，只涵盖该行列出的行为。“部分”指出仍有明确差距。“待实测”表示已有底层支持，但还缺少目标平台上的专门验收。“未实现”表示尚无相应的终端入口或协议实现。单项测试通过与全平台等价分别记录。目标平台为 Windows x64、macOS Intel 和 macOS Apple silicon。

## 官网功能清单

下表按官方功能页的顺序逐项列出。复查时应从 Brclio 主窗口进入终端，在新窗格中操作。[上游功能页](https://iterm2.com/features.html) · [Brclio 终端操作面板](../desktop/terminal/index.html)

| iTerm2 功能 | Brclio 状态 | 可复查的行为与差距 |
| --- | --- | --- |
| 分屏 | 可用 | 在同一标签先左右、再上下分屏，分别输入不同文本。拖动分隔条检查 PTY 尺寸，关闭一个窗格并检查其他会话。每个终端工作区最多运行 32 个会话。 |
| 全局热键窗口 | 未实现 | Brclio 主程序有全局快捷入口。终端可手动弹出。独立注册终端热键、跨应用隐藏/显示、贴屏及自动收起尚缺。 |
| 窗格内查找 | 可用 | 查找同一文本的多个匹配，切换大小写、整词和正则，查看计数并前后跳转。 |
| 自动补全 | 部分 | 输入刚刚输出的单词前缀，在“从滚动记录补全”中选择。候选来自当前窗格，最多 50 项。按主机或使用频率排序的命令建议尚缺。 |
| 键盘复制模式 | 部分 | 用方向键定位，Shift 扩选，Enter 复制，Esc 退出。尚未覆盖上游全部 Vim 键位、选择形状和移动粒度。 |
| 粘贴历史 | 部分 | 在某一窗格开启记录后，已粘贴文本可选择并再次粘贴。仅保留最近 20 条，每条最多 4096 个 UTF-16 码元。关闭记录或窗格时清空。跨会话复制历史及持久保存尚缺。 |
| 即时回放 | 部分 | 开启临时记录，输出或滚动几次后拖动时间轴查看文字快照。每窗格最多 120 帧并受总容量限制。颜色、图片、光标及逐帧画面还原尚缺。 |
| 可配置性 | 部分 | 可保存 Shell、起始目录、字体、历史行数、光标、对比度和颜色等参数，并读取 XML 格式的 .itermcolors。完整配置导入、键位和鼠标动作映射尚缺。 |
| Unix 风格交互 | 部分 | 可启用焦点跟随鼠标和选中即复制，可用快捷键管理标签及分屏。跨平台中键粘贴、修饰键映射和原生选择行为未全验收。 |
| 24 位色彩 | 待实测 | xterm.js 支持 SGR 真彩色，PTY 声明 truecolor。应分别从各平台真实 Shell 输出前景和背景 RGB 色块，与指定像素比对。 |
| 可读性 | 部分 | 修改最低对比度、光标形状、文本及光标颜色，观察低对比度输出。上游智能光标取色策略尚未比对。 |
| 鼠标事件上报 | 待实测 | 当前使用 xterm.js 的终端鼠标模式。需在两类系统的本地 TUI 中验证点击、拖动、滚动及退出后的常规选择。 |
| 系统通知 | 未实现 | 尚无针对终端响铃、后台活动、静默或作业结束的可配置系统通知。Windows 可采用系统通知中心。 |
| 全局搜索 | 部分 | 在不同标签输出独特文字，从“搜索所有窗格”定位结果。当前搜索打开的终端缓冲区，最多显示 50 项。会话归档及元数据查询尚缺。 |
| 带标签的配置 | 部分 | 创建两个带标签的命名配置，按名称或标签筛选并载入。最多保留 64 个。上游结构化查询语法和配置层级尚缺。 |
| 多语言文字 | 部分 | 渲染端启用 Unicode 11 字宽表，可验收中文、全宽字符、组合音标、emoji 和 IME。未覆盖上游 Unicode 版本、字素簇、双向文字及字体组合的全部差异。 |
| 触发器 | 未实现 | 暂无保存正则规则并针对持续到达的输出触发高亮、标记、提醒等动作的入口。 |
| 智能选择 | 未实现 | 常规拖选、按词选择可用。按规则识别路径、URL、电邮或引号范围，再绑定上下文动作的流程尚缺。 |
| Shell 集成 | 部分 | 在新会话启用后可按提示符跳转，支持完整命令边界的 Shell 可选取输出；另可手动添加标记。各 Shell 的覆盖范围见下表。按主机记录命令、常用目录与远端上传下载尚缺。 |
| 自动切换配置 | 未实现 | 当前可手动载入配置。按主机、用户、运行命令或目录规则匹配并自动切换尚缺。 |
| 行内图片 | 部分 | 有针对 iTerm2 单段内联 PNG 和 SIXEL 的像素测试。动画 GIF、Kitty 图形、多段文件传输或其他文件预览均不计入已验证范围。 |
| 逐行时间戳 | 未实现 | 回放帧显示采样时间。终端缓冲区每行的最后修改时间尚无记录及显示入口。 |
| 密码管理器 | 未实现 | 终端没有凭据库存、密码提示识别或受控填入界面。上游使用 macOS 钥匙串，Windows 等价实现需单独核验系统凭据保护。 |
| 高级粘贴 | 未实现 | 可正常粘贴及从临时历史中重贴。粘贴前编辑、逐行节奏和 Base64 等内容转换尚缺。 |
| 选区批注 | 未实现 | 可给所在行添加导航标记。对任意选区写批注、查看和删除批注的入口尚缺。 |
| 会话徽章 | 未实现 | 能显示 Shell、会话标题和状态。窗格叠加的徽章模板、主机/分支/变量插值尚缺。 |
| 输出捕获 | 未实现 | 可选择已完成命令的输出。跨命令按规则收集告警、在工具栏中列出并跳转到原始行的能力尚缺。 |

| 主题 | Brclio 状态 | 验收条件、现有实现及平台差异 |
| --- | --- | --- |
| 终端入口、标签与快捷键 | 部分 | 同一工作区可在主窗口和弹出窗口间移动，切换后原 PTY、输入及滚动内容应保留。可创建、重命名、切换、关闭标签。上游全部菜单、快捷键编辑器和操作面板尚缺。 |
| 布局保存与重建 | 部分 | 用名称保存分屏树、比例和 Shell 启动配置，重新打开时在现有标签之外创建新会话。可验证原标签仍可输入，布局中的进程具有新 PID。 |
| 崩溃后恢复原会话 | 未实现 | 上游可重连仍存活的后台 Shell。Brclio 的本地 PTY 服务随所属宿主退出，重新打开布局会启动新 Shell。 |
| 隐藏会话、标签分组 | 未实现 | 切换页面可保留会话。尚无单独收起并召回隐藏会话，或建立、折叠、重排命名标签组的入口。 |
| 会话归档、笔记与剪藏 | 未实现 | 临时回放可查看近期文字；导出或重新打开长期会话归档、会话笔记、保存及整理具体片段尚缺。 |
| 状态栏与会话状态 | 部分 | 当前显示 Shell、工作目录/状态和退出结果。缺少可配置组件、Git 分支、资源图表和应用上报的任务状态。 |
| 快速打开 | 未实现 | 终端内查找可以搜索输出。按会话名称、主机、目录或徽章统一检索并切换的入口尚缺。 |
| 字体与无障碍 | 部分 | 可选字体与字号，启用 xterm.js 屏幕阅读器模式。须分别验收 VoiceOver、Narrator、连字、回退字体和全宽字元。 |
| 选择命令及命令链接 | 部分 | 可从保存的命令边界选取输出。尚无对应上游的命令 URL、指定历史命令重新定位或分享命令选择。 |
| 动态配置 | 未实现 | 本地命名配置可持久保存。尚无监听外部配置文件目录、同步变化与按上游 GUID/继承规则合并的机制。 |
| tmux 控制模式 | 未实现 | 需要在 tmux -CC 连接后映射上游窗口、标签及窗格，双向同步布局并能断开和重连。终端中运行普通 tmux 的文本界面仅使用 PTY。 |
| SSH 集成与远端文件 | 未实现 | 本机安装的 ssh 客户端可作为普通终端程序使用。专用 SSH 配置、远端 Shell 跟踪、文件上传下载和断线重连尚缺。 |
| 协进程 | 未实现 | 尚无向独立本地子进程转接指定会话输入输出并管理其生命周期的用户入口。 |
| 配套命令行工具 | 部分 | 已支持的内联图片、标记控制序列可由客户端程序输出。上游 it2、imgcat 等命令、远端文件传输及安装工具没有随 Brclio 分发。 |
| 私有转义序列 | 部分 | 支持 OSC 133 的 A/B/C/D、OSC 1337 的 SetMark 和部分图片序列。按操作分别验收；文件传输、用户变量、块折叠、自定义按钮等协议均未完整实现。 |

| AppleScript、Touch Bar | 上游平台专有，未实现 | 脚本字典和 Touch Bar 只适用于特定 Apple 环境。Windows 可定义替代快捷操作和自动化接口，两者须单独定义、验收。 |
| 浏览器配置与浏览窗格 | 未实现 | 终端工作区尚无导航网页、维护浏览历史并与终端共享分屏的浏览器会话类型。 |

| 工作组与伴随应用 | 未实现 | 尚无工作组模板、主从会话协作、iTerm2 Buddy 配对和移动设备联动。 |

## 各 Shell 的命令标记

启动集成默认关闭，在“操作”中开启后创建新的会话。辅助脚本随桌面包本地分发，运行时不写用户启动文件。程序也可以自行输出协议标记。命令输出选择要求收到 C 与 D，一条手动标记只提供导航。记录限于当前窗格普通缓冲区，最多 512 项，滚动清理后旧标记失效。[上游 Shell 协议](https://iterm2.com/documentation-escape-codes.html) · [上游 Shell 集成](https://iterm2.com/documentation-shell-integration.html) · [本地实现](../desktop/terminal/command-marks.js)

| 环境 | 可验证行为与限制 |
| --- | --- |
| macOS zsh | 登录模式加载原有 .zshenv、.zprofile、.zshrc、.zlogin。precmd/preexec 提供命令结束与输出边界。实际 PTY 回归覆盖带单引号的路径、定制 prompt、上一条命令返回 23、下一条命令读到 23 以及退出码 19。 |
| macOS Bash | 保留登录模式及已有 PROMPT_COMMAND。系统 Bash 3.2 支持提示符导航。Bash 4.4 及以上通过 PS0 补充命令开始边界。用户启动文件重置这些变量时可能不产生标记。系统 Bash 实际 PTY 回归验证既有 prompt hook、登录文件与退出状态。 |
| Windows PowerShell / PowerShell 7 | 继续加载本机配置。支持时包装现有 prompt 与 PSConsoleHostReadLine。无 PSReadLine 时只标记提示符；执行策略及受限语言模式可能阻止启动集成。Windows 原生回归检查自定义提示、读取器、成功/失败标记及原生命令退出码。完整 ConPTY/PSReadLine 组合需按系统版本实测。 |
| Windows cmd.exe | 保留原有 PROMPT 并加入提示符首尾标记。缺少可靠的命令执行前后钩子，默认无法自动划定命令输出范围。 |
| 其他登录 Shell、嵌套 Shell、SSH | 本地会话仍按原 Shell 启动。若相应 Shell 自行发送兼容控制序列，渲染器可处理。fish、tcsh、xonsh 和远端安装不在内置辅助脚本覆盖范围。 |

## 复查方法

1. 在项目根目录运行 `npm ci`，再运行 `node --test desktop/terminal-*.test.cjs`。Windows 可在 Git Bash 中执行，或显式传入测试文件。真实 PTY 用例使用临时工作目录。[PTY 测试](../desktop/terminal-pty.test.cjs) · [命令标记测试](../desktop/terminal-marks.test.cjs) · [布局测试](../desktop/terminal-arrangements.test.cjs)
2. 在 macOS 或 Windows 上运行 `npm run sync` 和 `node scripts/verify-terminal.cjs`。用 `BRCLIO_SMOKE_EXECUTABLE` 指向当前架构已打包的可执行文件，可复查发行布局及原生模块。UI 测试覆盖的具体交互以脚本断言为准。[桌面端到端测试](../scripts/verify-terminal.cjs) · [图片与 Unicode 像素测试](../scripts/verify-terminal-output.cjs)
3. 三平台构建由同一工作流分别检查，看对应提交的 Windows x64、macOS Intel、macOS Apple silicon 三项结果。较早版本的通过记录只能证明该次构建。[打包验收工作流](../.github/workflows/desktop-terminal.yml)
